Built using a combination of HTML, CSS, and JavaScript, this project demonstrates skills in static web development and interactive functionality, including transaction simulations and local data management using localStorage.

Bill Buddy: Bill Management & Payment Reminder App

A mobile application developed with Flutter to help users track and manage their bills. The app leverages Firebase Firestore for real-time data storage, Firebase Authentication for user sign-in, and Firebase Messaging along with flutter_local_notifications to send timely payment reminders. This project showcases my expertise in cross-platform development and backend service integration.
